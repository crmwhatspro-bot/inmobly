Preparar página de emprendimento

Ferramenta interna Punto Alto — não é parte do site do broker. Puxa as fotos já cadastradas de um imóvel no CMS (via imoveis/{id}/fotos, leitura pública, sem necessidade de login) para reaproveitar na página bespoke estilo Nobile Inn. Se o imóvel ainda não tem fotos, gera os placeholders com o tamanho ideal para a equipe saber exatamente o que produzir/fotografar.

1. Escolha o imóvel

2. Fotos existentes deste imóvel

Fotos do CMS saem a 900px de largura — ótimo para a seção de galeria da página bespoke. Para o hero (fundo full-bleed), o ideal é 1440px+; se a melhor foto disponível aqui for a única opção, ela ainda funciona (o hero usa object-fit/background-size: cover), mas o resultado fica mais nítido com uma imagem maior.

2. Sem fotos cadastradas ainda — spec de imagens necessárias

Nenhuma foto encontrada em imoveis/{id}/fotos para este imóvel. Tamanhos abaixo são os mesmos já usados em produção (verificados nos arquivos reais do projeto de referência) — não são um chute.
